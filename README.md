 Huber Food Delivery App

Huber is a full-featured food delivery application built completely by me (UI, UX, Flutter programming, backend integration, and deployment).  
This project showcases my ability to design, develop, and integrate a complete app experience from start to finish.

# Features
- Over 60 custom-designed screens built in Flutter.
- Fully integrated backend with Firebase (auth, payments, data storage).
- Component-based, scalable UI with custom themes.
- Interactive navigation, modals, and dialogs already wired.
- Support for multiple restaurants, orders, and tracking.

## 🛠️ Tech Stack

- **Frontend**: Flutter 
- **Backend**: Firebase (Auth, Firestore, App Check), Stripe integration
- **Design Tools**: Figma, Adobe XD (UI/UX)
- **Integrations**: Payment gateways, push notifications
